01 / WORKFLOW

把一次性重写，变成可回看的小步迭代。

每一步都能被检查、拒绝或回滚。当前 Agent 负责语义判断，工具负责有限修改和本地边界。

01 / INPUTPreserved

原始 Skill 不被覆盖。

工具只读取用户明确提供的文件，并将候选修改写入新的目标路径。原始 SKILL.md 始终是可以比较和回滚的基线。

input SKILL.md
write candidate/SKILL.md
state original preserved
02 / TARGETS

一份规范 Skill，多个 Agent 入口。

打包器将同一份 canonical SKILL.md 映射到常见 Coding Agent 的目录约定，降低迁移和手工整理成本。

03 / SAFETY

边界不是附加项，而是产品的一部分。

Better Skills SkillOpt 的输出是新文件，不是安装器。它不访问网络、不启动外部进程，也不自动修改任何 Agent 或系统目录。

◈

Safe by default

在进入 ZIP 之前，候选内容会经过结构、路径、危险模式和疑似密钥检查。

  • 原始 Skill 只读，候选输出单独保存
  • 不安装依赖，不执行候选 Skill
  • 不自动复制到 Agent 配置目录
  • ZIP 需要人工审阅后再部署
